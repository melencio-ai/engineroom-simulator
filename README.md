# Engine Watch — Marine Engine Room Simulator

A PSP-first hybrid marine engine room simulation project, combining a navigable engine room with an Engine Control Room (ECR).

Development happens on feature branches. Planned first playable slice: walk from the ECR to the engine room, start a lubricating-oil pump locally, and verify pressure and pump status back in the ECR.

> Early simulation values are illustrative, not shipboard operating instructions.
